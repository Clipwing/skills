WHAT COMES THROUGH
01

Text stays text.

Keep editable text layers. Fonts are matched when available, with substitutes reported when needed.

02

Boxes become shapes, images and video become footage, and nested compositions become precomps.

03

Animation becomes keyframes. A frame comparison helps you see how the After Effects result matches the original.

GET STARTED

One skill.
Your next workflow.

Use the packaged download in Claude, or install the source folder in Claude Code.

01 / INSTALL

Add it to Claude Code

Copy the full skill folder into your personal skills directory:

macOS~/.claude/skills/hyperframes-to-after-effects/
Windows%USERPROFILE%\.claude\skills\hyperframes-to-after-effects\

For one project, use .claude/skills/ inside that project. Include all scripts and references, then restart Claude Code.

Using the .skill package in Claude

Download the package above. Open it in the Claude app and choose Save skill. Running the conversion requires access to your local HyperFrames project and After Effects; Claude Code is the documented local workflow.

02 / CHECK YOUR SETUP

Have these ready

  • Node.js 18+ and a HyperFrames project that renders.
  • After Effects 2023+ with “Allow Scripts to Write Files and Access Network” enabled in scripting preferences.
  • ffmpeg for media conversion and frame comparison.

Tested on Windows. macOS support is included but has not yet been verified.

03 / ASK CLAUDE

Open your HyperFrames project

“Convert this to an After Effects project.”

The skill checks your setup, exports the composition, builds the After Effects project and compares frames.

BEFORE YOU BEGIN

Know what stays approximate.

Some web effects need a different representation in After Effects. 3D transforms flatten to 2D; gradients and complex shadows become images with animated transforms. Font substitution and blend modes can change the look.
