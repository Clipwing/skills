WHAT YOU GET
01

Real, not generated.

02

03

Checked before you hear it.

GET STARTED

One skill.
Your next workflow.

Use the packaged download in Claude, or install the source folder in Claude Code.

01 / INSTALL

Add it to Claude Code

Copy the full skill folder into your personal skills directory:

macOS~/.claude/skills/real-sfx/
Windows%USERPROFILE%\.claude\skills\real-sfx\

Then point it at your sound library with python scripts/setup.py init. No library yet? It starts with 78 free UI sounds.

02 / CHECK YOUR SETUP

Have these ready

  • Python 3.9+ and FFmpeg in PATH (on macOS, ffmpeg-full from Homebrew).
  • A folder of sound effects you have the rights to use.

Tested on Windows and macOS.

03 / ASK CLAUDE

Point it at your video

“Add sound design to this render.”

You get a new MP4, a separate SFX track in WAV and a short report.

BEFORE YOU BEGIN

Bring your own sounds.

The skill ships without a sound library and never copies yours anywhere. Claude can't hear, so it picks sounds by measured character and tags, and tells you which moments to check by ear.
